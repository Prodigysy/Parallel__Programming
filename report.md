# Отчет по лабораторной работе №3

## Задание
Разработать программу на языке C/C++ для параллельного перемножения матриц с использованием MPI.
Входные данные — матрицы, сохранённые в текстовых файлах.
Результаты работы — файл с произведением, замер времени исполнения и размеры задачи.
Обязательна проверка корректности с использованием внешних инструментов (например, Python с NumPy).

## Реализация
Проект реализован на C++ с применением библиотеки MPI (в частности, MPICH). Основу составляет класс Matrix, содержащий методы для генерации, чтения, записи и параллельного перемножения матриц.

### Алгоритм работы:
1. Генерация двух случайных матриц на процессе с рангом 0.
2. Распределение строк первой матрицы между процессами.
3. Рассылка второй матрицы целиком всем процессам.
4. Каждый процесс умножает свою часть строк первой матрицы на всю вторую матрицу.
5. Собираются частичные результаты в итоговую матрицу на процессе 0.
6. Результат сохраняется в файл (только для одной размерности из 10).
7. Производится 10 запусков для каждой размерности, рассчитывается среднее время.

### Верификация
Для верификации используется Python-скрипт, в котором матрицы из файлов загружаются и перемножаются с помощью numpy.dot(). Результат сравнивается с тем, что выдала C++ программа.

## Вывод
Использование MPI позволило добиться значительного ускорения при выполнении матричного перемножения. Особенно эффективно это проявляется на крупных задачах и при большом числе потоков.
В отличие от OpenMP, MPI обеспечивает лучшее масштабирование при работе в распределенной среде, хотя и требует дополнительных затрат на передачу данных между узлами.
В целом, MPI подтвердил свою надежность и эффективность в задачах подобного класса.
