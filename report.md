# Отчет по лабораторной работе №2

## Задание
Написать программу на языке C/C++ для перемножения двух матриц с использованием OpenMP для параллельных вычислений.
Исходные данные: файл(ы) содержащие значения исходных матриц.
Выходные данные: файл со значениями результирующей матрицы, время выполнения, объем задачи.
Обязательна автоматизированная верификация результатов вычислений с помощью сторонних библиотек или стороннего ПО.

## Реализация
На языке C++ написан класс `Matrix`, реализующий хранение и операции над матрицами, включая их умножение.

### Алгоритм работы программы:

1. **Подготовка тестовых данных**:
   - Создаются пары квадратных матриц возрастающей размерности (от 100×100 до 1000×1000 с шагом 100)
   - Элементы матриц заполняются псевдослучайными числами в диапазоне [0, 1]
   - Каждая пара матриц сохраняется в отдельных файлах с именами `matrix_A_N.txt` и `matrix_B_N.txt`

2. **Процесс вычислений**:
   - Для каждой размерности выполняется серия из 10 независимых измерений
   - Умножение матриц осуществляется с использованием технологии OpenMP
   - Фиксируется время выполнения операции с точностью до микросекунд

3. **Сохранение результатов**:
   - Полученные матрицы-произведения записываются в файлы `result_N.txt`
   - Время выполнения для каждого теста сохраняется в лог-файл

4. **Статистическая обработка**:
   - Для каждой размерности вычисляется среднее время выполнения
   - Определяется стандартное отклонение по серии измерений

5. **Верификация корректности**:
   - Реализован скрипт на Python с использованием NumPy
   - Выполняется поэлементное сравнение результатов с эталонными значениями
   - Проверка осуществляется с относительной точностью 1e-8

### Параллельная реализация
Для ускорения вычислений использованы:
1. **Основные директивы OpenMP**:
```cpp
#pragma omp parallel for  // Параллельный цикл
#pragma omp simd         // Векторизация
```
2. **Ключевые оптимизации**:
- Динамическое распределение нагрузки (`schedule(dynamic)`)
- Локализация данных потоков (`private`)
- Редукция переменных (`reduction`)

3. **Конфигурация**:
- Тестирование на 4/8/12 потоках
- Разные стратегии планирования
- Оптимизация под кэш процессора

Для оценки эффективности:
- Замеры времени выполнения
- Анализ ускорения
- Проверка масштабируемости
