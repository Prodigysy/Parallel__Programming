# Отчет по лабораторной работе №4

## Задание
Реализовать программу на языке C/C++, выполняющую умножение матриц с использованием графического процессора (GPU) через технологию CUDA.
Входные данные: файлы с элементами исходных матриц.
Выход: файл с итоговой матрицей, время выполнения операции, характеристики задачи.
Дополнительно: обязательная проверка корректности результата с использованием стороннего ПО или библиотек (например, NumPy/Python или MATLAB).

## Реализация
Для работы с матрицами создан класс Matrix, предоставляющий базовые функции: хранение, доступ к элементам, чтение и запись в файлы, а также умножение.
Алгоритм умножения реализован на CUDA: данные копируются в память GPU, далее выполняется параллельное вычисление по классической схеме "строка × столбец". Результаты передаются обратно в ОЗУ.
### Алгоритм работы программы:
1. Генерируются квадратные матрицы размером от 100×100 до 1000×1000 со случайными значениями.
2. Матрицы сохраняются в текстовые файлы формата aN.txt и bN.txt, где N — размерность.
3. Происходит передача данных на GPU и запуск CUDA-ядра, выполняющего умножение.
4. Результат сохраняется в файл matrix_C_N.txt.
5. Для каждой размерности производится 10 запусков, после чего вычисляется среднее время выполнения.
6. Проверка точности выполняется с помощью Python (NumPy) путём сравнения результата CUDA с результатом numpy.dot().

### Особенности CUDA-реализации:
Используется глобальная память (cudaMalloc, cudaMemcpy).
Параллелизм организован через сетку блоков (grid) и потоков (threads).

## Вывод
Применение параллельных вычислений на GPU позволило существенно сократить время выполнения по сравнению с традиционной реализацией на CPU. Особенно заметно преимущество CUDA при работе с крупными матрицами, где ускорение достигает десятков раз.
Также была подтверждена корректность работы CUDA-реализации: сравнение с результатами, полученными через NumPy, показало полное совпадение.
